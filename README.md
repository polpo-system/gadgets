# gadgets

The Gadgets system of ETH Oberon System 3 for [polpo](https://github.com/polpo-system/polpo): the
component framework of the Oberon desktop (Gadgets, Display3, Attributes, Links, Effects) and its
standard classes: panels, buttons and the other basic gadgets, text fields, lists, text and panel
documents, desktops, icons, name plates, scroll bars, the gadget inspector Columbus and more.

The sources come from ETH Linux Oberon (OLR, 2017), converted to plain text; the first commit has
them unchanged, the changes for polpo follow, one commit each.

The applications built on gadgets (Rembrandt, Leonardo, the HTML browser, ...) and the games are
packages of their own (gadgets-...). Gadgets are optional: polpo's desktop works without them.
